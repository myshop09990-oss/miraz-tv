এটি GitHub Pages-এর Local Draft Editor।
এখানে পরিবর্তন করলে প্রথমে শুধু এই ফোনে খসড়া সেভ হবে। সব দর্শকের জন্য প্রকাশ করতে নিচের Copy JSON নিয়ে GitHub-এ content.json আপডেট ও Commit করতে হবে। কোনো গোপন অ্যাডমিন পাসওয়ার্ড নেই—GitHub অ্যাকাউন্টের অনুমতিই প্রকাশ নিয়ন্ত্রণ করে।

পরিবর্তন প্রকাশ করুন

প্রথমে JSON কপি করুন; তারপর GitHub-এর content.json এডিট করে পুরো লেখা বদলে Commit করুন।

২. GitHub Editor খুলুন

GitHub-এ কোড ঘরে সব লেখা Select all করে নতুন JSON Paste করুন → Commit changes করুন। এতে পাবলিক ওয়েবসাইট আপডেট হবে।
Movies যোগ করলেও আগের Channels/Episodes নষ্ট হবে না, যদি এই ফোনের বর্তমান ড্রাফটেই এডিট করেন।

শুধু আপনার নিজের/অনুমোদিত ভিডিও ও স্ট্রিম ব্যবহার করুন। MP4 ভিডিও HTTPS লিংক ভালো কাজ করে; HLS ম্যানিফেস্ট (.m3u8) চালাতে উৎস সার্ভারের CORS অনুমতি প্রয়োজন হতে পারে। GitHub Pages নিজে ভিডিও হোস্টিং নয়।
